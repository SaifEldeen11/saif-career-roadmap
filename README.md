# Saif — Career Roadmap

A personal, interactive career roadmap from October 2026 through October 2028, covering backend engineering, applied AI, cybersecurity, and preparation for university and student roles in Germany.

## Features

- Expandable two-year roadmap and supporting guidance
- Applied AI and cybersecurity project paths
- Browser-local evidence checklist and text export
- Responsive layout, subtle animations, and reduced-motion support
- Print support and official source links

## Run locally

Use any static web server from this directory, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## GitHub Pages

Publish the `main` branch from `/ (root)` in **Settings → Pages**. No build dependencies are required. `.nojekyll` serves these static files directly.

## Files

- `index.html`: layout and roadmap guidance
- `style.css`: styling, responsive layouts and animation
- `app.js`: roadmap phases, specialty tabs, progress tracking and export

Progress is stored only in the current browser's local storage. It is not synced across devices. Sources reflect the research date shown on the site, and hiring outcomes are not guaranteed.
